# 📦 [CurlShot](https://curlshot.com)


> **Screenshot API that turns a URL, HTML or Markdown into PNG, JPEG, WebP, PDF or a scrolling MP4, WebM or GIF video, rendered in a real Chromium browser. Full page, device presets, element capture, dark mode, ad and cookie-banner blocking, async webhooks, bulk jobs and a remote MCP server for AI agents.**
