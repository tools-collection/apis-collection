# 📦 [LurkAPI](https://lurkapi.com/docs)


> **LurkAPI is a REST API for public social media data: posts, profiles, comments, video transcripts and ads from the Meta, Google, TikTok and LinkedIn ad libraries, from 16 platforms as JSON. The same endpoints are served as a remote MCP server. 100 free credits at signup, then one-off packs from $9 for 10,000 credits.**
